# Publication checklist

Complete these checks before making the Pages project public.

- [ ] Confirm permission to redistribute every downloadable data package.
- [ ] Confirm that Cochrane-derived values are distributed consistently with
      the applicable licence and attribution requirements.
- [ ] Confirm that no unpublished, confidential, or participant-level data are
      present.
- [ ] Verify all citations, source descriptions, and evidence-release dates.
- [ ] Review the canonical analysis and every enabled sensitivity specification.
- [ ] Confirm that low-trial-count, subgroup, ecological, MID, and multiplicity
      limitations remain visible.
- [ ] Test keyboard navigation, mobile layout, downloads, and social preview.
- [ ] Add maintainer, funding, and conflict-of-interest statements.
- [ ] Establish a correction address and documented update schedule.
- [ ] Archive the release and record its permanent citation.
